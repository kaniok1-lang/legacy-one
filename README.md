# Legacy One

## by My Pamu

Legacy One est une application web premium de gestion de conciergerie développée par My Pamu.

## MVP 1.0

### Fonctionnalités

- Dashboard
- Gestion des prospects
- Gestion des clients
- Vente des abonnements
- Tableau de bord commercial

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Hosting

## Objectif

Créer le logiciel de conciergerie le plus simple, le plus élégant et le plus rapide à utiliser.

## Version

MVP 1.0
